# Contextual feedback

The selected delegated direction is pane-local in-flow outcomes and persistent offscreen attention, with no permanent idle footer. Standard navigation destinations have visible names. Refresh feedback belongs to Refresh and the pull indicator. Undo has no automatic timeout: dismissal changes presentation only, while Changes remains the durable history entry. Unresolved outcomes and retained edits remain reachable until resolution. See [the evaluated UX plan](requirements-plan.json) for six observable scenarios and counterexamples.

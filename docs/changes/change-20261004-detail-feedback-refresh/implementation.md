# Implementation

Existing closed pure factories expose Action/catalog validation and date-pair responsible-field feedback. The DOM attaches nearby messages and accessibility state without replacing inputs or raw proposals. Ordinary field-validation errors do not duplicate in the remote save panel; conflict/unknown/transport feedback is preserved.

Refresh retains its icon and stable accessible name, with one internal live status description, aggregate state and an actual-writing animation flag. It is the last header action. Flag has a larger effective gap and separator while retaining orange. Text clock styling uses tabular numerals and preserves HH:mm placeholders and partial values.

Native Profiles are used. No development-loop kernel execution, backend/schema change, Git operation or hosted deployment is performed.

Local implementation and acceptance are complete; see [verification](verification.md) for exact target/root/independent scopes and limitations. Source remained frozen after review.

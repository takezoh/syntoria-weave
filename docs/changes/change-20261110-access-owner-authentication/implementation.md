# Implementation

Access signature verification is an effect adapter with fixed issuer and keys.
Authentication maps the verified owner to the existing SQL binding and mints one
shared AI or person capability. Revalidation checks JWT and admission inside each
transaction. The browser uses same-origin API forwarding and a separate login
window so its mounted proposal survives. New delegation accepts any AI only;
historical DTOs remain readable for audit. Migration 0015 and its checksummed
JavaScript companion update current heads transactionally without rewriting
history, receipts or arbitrary UTF-16 strings. Cutover requires a write fence and
cursor epoch rotation. Cloud Tasks uses the original forwarded Google token.
Terraform binds backend invocation to the dedicated Gateway account; old Secret
Manager resources remain declared to prevent accidental credential deletion.

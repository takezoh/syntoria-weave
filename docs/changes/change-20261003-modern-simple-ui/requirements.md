# Requirements

The shared Ariadne interface must be modern, simple and intuitive in a conversation side panel and full presentation. A list-first workspace uses named navigation, concise rows, selected-action details and coherent generated vector icons. Capture preserves the exact original notes and caller title.

The [accepted UX artifact](evidence/requirements-plan.json) records observable scenarios UAC-001 through UAC-010; its [independent assessment](evidence/requirements-verdict.json) approves revision `native-author-20261003-3`. Existing action meanings and persistence guarantees remain authoritative.

All draft fields, selected editor, open details, focus/caret, review and exact unknown request survive refresh, filtering and supported mode changes. A dirty action outside the current filter remains reachable without being presented as current-view membership. Conflicts preserve both the latest correction and proposal. Review remains scrollable and keyboard/touch accessible at narrow widths; Back/Escape does not save.

The official protocol provides `inline` and `fullscreen`; it does not provide a `sidebar` wire mode. Unsupported hosts expose truthful availability. Web presentation is identified separately from ChatGPT host presentation. Actual host acceptance requires a separately requested deployment.

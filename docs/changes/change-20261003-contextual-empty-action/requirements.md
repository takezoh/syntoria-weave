# Requirements

Given an exact Project or Tag, Add saves one empty ordinary Action in that context and opens Title. Inbox creates unassigned; Flagged directly flagged. Unassigned and Untagged are explicit targets. All classification views, History, Perspectives, unavailable selections and deferred-only filters disable Add with a reason.

Title and Notes use the ordinary inspector; Untitled is a display placeholder. Quick-title/capture forms are removed; MCP capture remains. Empty actions are not automatically deleted. Missing responses retain frozen context and exact operations. Receipt identity alone selects the created Action. Navigation/Back/Close, nine inputs, other proposals and a last-created access route survive recovery.

Counterexamples: selecting by blank title or last row, falling back to Inbox, fabricating dates, new retry IDs, translating raw Notes or accepting malformed receipt proof.

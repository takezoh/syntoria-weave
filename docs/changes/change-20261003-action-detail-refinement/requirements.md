# Requirements

Flag is an accessible icon-only button at the right of the lifecycle controls. It reflects the current draft and retains later proposals during pending writes and unknown outcomes. Action details use always-visible sections. The redundant classification sentence and timezone paragraph are absent.

One header icon represents all Action/catalog proposals, local raw date errors, composition and creation-name proposals. Unknown/recovery and failures dominate actual write animation, then pending proposals, then saved. Initial loading is never saved. The spinner represents actual writes, not reads/previews, and respects reduced motion. Ordinary Saved feedback is absent; actionable failures, unknown recovery and saved-value conflict comparisons remain reachable.

Defer is one date/time pair. The first date-only choice resolves 09:00 in the explicit client timezone. Later date changes preserve custom time, seconds and milliseconds. Explicit date clearing releases Defer. Empty/partial time and badInput are retained proposals and cannot release Defer or default silently. Saved instants do not change on rendering or timezone changes. DST gaps/folds are rejected.

Existing autosave, original-node IME, exact unknown retry, catalog editing, display checkboxes and native tree gutter behavior remain intact.

# Requirements

Bring ChatGPT plugin guidance into alignment with the deployed collaboration contract: up to three retained proposals, selection and editing, approval cancellation without deletion, separate Action lifecycle and run reports. Explain Remote MCP resource notifications without promising unsupported ChatGPT wake-up or direct model access to protocol methods. Preserve the existing registered-app dependency and host-managed OAuth connection.

An installed package must contain its referenced collaboration documentation and the same shared UI bytes as the build. Do not introduce a second MCP connection or ship deployment settings or credentials.

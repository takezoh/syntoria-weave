# Requirements

Tree rows provide insertion and outdent targets without a separate Top level drop space. A final visible child bottom-edge drop at root indentation appends at root. The visible guide names the destination depth before release. Project rows support sibling order and parent changes; Tag rows support parent changes only. Action-to-catalog center drops retain direct classification, and catalog movement never changes Action membership.

Shift contiguous selection remains Action-only. Cycles and incompatible kinds are rejected. Native mouse, pointer/touch and keyboard operations resolve the same meaning and preserve exact unknown requests and newer proposals.
